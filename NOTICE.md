# Template provenance

This website directly uses and adapts two MIT-licensed open-source templates:

- **AstroPaper** by Sat Naing is the technical base for the Astro project, blog,
  content collections, search, RSS, sitemap, layouts, theme system and blog UI.
  Source commit: `fb336a6c8540f5b0e38b6858fa4004473acda722`.
- **DevPortfolio** by Ryan Fitzgerald supplies the portfolio home-page visual
  system and original Hero, About, Projects, Header and Footer component structure.
  Source commit: `852d650fb0a8cf0c98f874af5a56a0a9b7d7d4b7`.

Both templates were localized, made RTL-aware and populated with Hossein
Mokhtari's portfolio content. The AstroPaper MIT license remains in `LICENSE`;
the DevPortfolio MIT license is preserved in `licenses/DEVPORTFOLIO-LICENSE.md`.

The bundled Vazirmatn font is distributed under the SIL Open Font License by
its respective authors via the Fontsource package.
