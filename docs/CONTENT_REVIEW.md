# بازبینی محتوای عمومی

متن Case Studyها از روی کد، README، routeها، مدل‌ها، تست‌ها و فایل‌های استقرار
پروژه‌های محلی نوشته شده است. پیش از انتشار نهایی این موارد توسط حسین تأیید شوند:

| پروژه | مواردی که باید تأیید شود |
| --- | --- |
| Mecoin | نام عمومی محصول، فعال‌بودن نسخه فعلی و امکان اشاره به اقتصاد مأموریت‌محور |
| AI Business Agent | نام عمومی مشتری/محصول و امکان توضیح جریان ثبت کسب‌وکار |
| Data Platform | اینکه Avval، IranTejarat و Google Maps زیر یک Case Study جامع نیز معرفی شوند |
| Mikham Marketing | امکان اشاره عمومی به Attribution، QR، امتیاز و پاداش |
| Telepress | امکان استفاده از نام WordPress و Telegram در توضیحات عمومی |
| سایر ربات‌ها | وضعیت production/active/completed و نام عمومی صحیح |

## اطلاعاتی که عمداً منتشر نشده‌اند

- آدرس Endpointهای خصوصی و Tokenها
- نام و اطلاعات مشتریان
- شماره تلفن، شناسه کاربر و داده‌ی واقعی آگهی‌ها
- آمار استفاده، درآمد، تعداد کاربر یا درصد بهبود بدون مدرک
- لینک مخزن پروژه‌های Mikham و repositoryهای دارای runtime file

## اطلاعات مفید برای نسخه بعدی

- تصویر یا Screenshot پاک‌سازی‌شده برای پروژه‌های شاخص
- بازه‌ی زمانی تقریبی هر پروژه
- نقش دقیق در پروژه‌هایی که همکار دیگری داشته‌اند
- نتیجه‌ی قابل‌اندازه‌گیری و قابل‌اثبات هر پروژه
- سوابق تحصیلی یا کاری در صورت تمایل به انتشار
